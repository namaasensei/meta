# Arsalan Akhtar — Portfolio Website

Static HTML/CSS/JS website designed for GitHub Pages.

## Files
- `index.html` — website structure/content
- `style.css` — responsive styling
- `script.js` — animations, mobile menu and contact form

## Before publishing
1. Open `script.js`.
2. Change `BUSINESS_EMAIL` to the email address you actually use.
3. Replace the `YOUR PHOTO` placeholder in the About section with your professional headshot.
4. Replace the case-study placeholders with verified campaign results only.
5. Update the LinkedIn and Instagram links in `index.html`.
6. Add your real article URLs in the Insights section.

## GitHub Pages
Upload all three files to the root of your GitHub repository.
Then go to:
Settings → Pages → Deploy from branch → main → / (root) → Save

For a custom domain, keep the repository's Pages setting enabled and configure the domain DNS at your registrar.
